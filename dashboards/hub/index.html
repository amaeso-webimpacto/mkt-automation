02Datos para meter a mano

Lo que cada panel necesita del equipo en «Editar datos». Marca cada dato como hecho cuando lo hayas metido; la siguiente actualización vuelve a revisarlo.

03Crear panel nuevo

Rellena los datos y copia la petición para pegarla en una conversación nueva de Claude, con la skill panel-email-cliente (modo A). Al publicar el panel, Claude lo añade a este listado.

04Añadir panel existente

Pega el enlace de un artefacto «Panel Email <Cliente>» que ya esté publicado.

Este listado solo guarda el nombre, el enlace, el estado y los datos pendientes de cada panel, nunca cifras. Las cifras viven en el panel de cada cliente.
