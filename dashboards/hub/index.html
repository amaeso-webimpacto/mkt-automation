01Paneles

«Actualizar» abre una sesión de Claude Code para ese cliente con la skill panel-email-cliente (modo B). Cada sesión trabaja con un solo cliente y, al terminar, deja aquí el resultado y los datos que faltan por meter a mano.

Todavía no hay paneles. Crea uno o añade uno que ya exista en los formularios de abajo.

02Datos para meter a mano

Lo que cada panel necesita del equipo en «Editar datos». Marca cada dato como hecho cuando lo hayas metido; la siguiente actualización vuelve a revisarlo.

03Crear panel nuevo

Abre una sesión de Claude Code con la skill en modo A. El panel aparece en el listado como «Creando» y la sesión le pone el enlace al publicarlo.

04Añadir panel existente

Pega el enlace de un artefacto «Panel Email <Cliente>» que ya esté publicado.

Este listado solo guarda el nombre, el enlace, el estado y los datos pendientes de cada panel, nunca cifras. Las cifras viven en el panel de cada cliente. Para lanzar sesiones hace falta el conector Claude Code Remote en claude.ai.

Se abrirá una sesión nueva de Claude Code a tu nombre con esta petición. Puedes seguirla desde «Ver sesión».
